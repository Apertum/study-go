# internal/config

В этом пакете хранятся конфигурации приложения.

Загрузку конфигурации можно реализовать из различных источников, например: файлов, переменных окружения, баз данных и других.

Сервер читает конфигурацию в `ParseFlags()` из `init()`: сначала значения флагов, затем переменные
окружения — непустая переменная переопределяет флаг.

## Настройки сервера

| Флаг | ENV | По умолчанию | Эффект |
| --- | --- | --- | --- |
| `-a` | `SERVER_ADDRESS` | `:8080` | адрес основного слушателя: HTTP либо HTTPS |
| `-b` | `BASE_URL` | `http://short.ru/` | базовый префикс коротких URL |
| `-f` | `FILE_STORAGE_PATH` | `data.json` | файл хранения, когда база данных не подключена |
| `-d` | `DATABASE_DSN` | пусто | DSN PostgreSQL; пусто — работать по файлу |
| `-k` | `COOKIE_KEY` | `thisSuoerSecretMyKey` | ключ HMAC-SHA256 подписи куки `user_id` |
| `-audit-file` | `AUDIT_FILE` | пусто | путь к файлу аудита (JSONL) |
| `-audit-url` | `AUDIT_URL` | пусто | URL приёмника аудита |
| `-s` | `ENABLE_HTTPS` | `false` | включить HTTPS и редирект с HTTP |
| `-cert-file` | `CERT_FILE` | `cert.pem` | PEM-сертификат TLS; выпускается сам, если отсутствует |
| `-key-file` | `KEY_FILE` | `key.pem` | PEM-закрытый ключ к `-cert-file`, права `0600` |
| `-http-addr` | `HTTP_SERVER_ADDRESS` | `:8081` | адрес HTTP-слушателя редиректа на HTTPS |

## Включение HTTPS

Значение `ENABLE_HTTPS` разбирает `ParseEnabled` этого пакета (не `ParseFlags()`): флаг `-s` и переменная,
переменная приоритетнее; допустимы `1`, `t`, `TRUE`, `true`, `True`, `0`, `f`, `FALSE`, `false`, `False`.
Другое значение завершает процесс до прослушивания портов, в сообщении именем переменной остаётся её значение.

Материалы TLS, параметры слушателей редиректа и проверку их совпадения делает пакет
[`internal/secure`](../secure/doc.go): `go doc ./internal/secure`.
